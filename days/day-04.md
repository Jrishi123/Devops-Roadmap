# Day 04 — Networking for DevOps

**Week 1: DevOps Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** IP, CIDR, DNS, ports, TCP/UDP, HTTP, TLS, routing and diagnostic tools.

## Learning objectives
- Explain DNS resolution and TCP connection establishment
- Read CIDR ranges and identify network/broadcast addresses
- Use curl, dig, ping, ss and traceroute
- Diagnose common connection failures

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Inspect local interfaces and routes
2. Resolve a domain with dig/nslookup
3. Use curl -v and openssl s_client against a test endpoint
4. Run a local Nginx server and test ports

## Assignment and deliverables
- networking-lab.md with command outputs
- Network troubleshooting decision tree

## Checkpoint
Explain 0.0.0.0 vs 127.0.0.1; DNS A vs CNAME; TCP vs UDP.
