# Day 17 — Machine Learning Concepts

**Week 3: AI Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** Features, labels, training/testing, supervised/unsupervised learning, overfitting and evaluation.

## Learning objectives
- Explain training vs inference
- Identify features and labels
- Explain overfitting and data leakage
- Choose basic classification/regression metrics

2. Train a simple scikit-learn model
3. Split train/test data
4. Evaluate with suitable metrics and document limitations
