# Day 26 — Containerize & Test the Capstone

**Week 4: AI + DevOps Integration**  
**Estimated time:** 3–4 hours  
**Focus:** Multi-stage Docker builds, Compose, health checks, non-root containers and integration tests.

## Learning objectives
- Build frontend and backend images
- Use Compose for local stack
- Add health checks and persistent vector data where needed
- Scan and harden containers

2. Create Compose stack
3. Add .dockerignore and health checks
4. Run end-to-end smoke tests

## Assignment and deliverables
