# Day 16 — Python for AI Engineering

**Week 3: AI Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** Python data structures, functions, typing, virtual environments, packages, APIs and notebooks.

## Learning objectives
- Build clean Python modules
- Use virtual environments and dependency files
- Read/write JSON and CSV
- Call a REST API and handle errors

| Activity | Time |
|---|---:|

## Practical lab
1. Create a Python 3.11 virtual environment
2. Build a CLI that reads JSON logs
3. Add type hints, logging and unit tests
4. Call a public sample API with timeout and error handling

## Assignment and deliverables
- ai-foundations/log_cli.py
- requirements.txt or pyproject.toml
- Unit tests
