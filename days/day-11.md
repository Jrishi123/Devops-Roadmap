# Day 11 — Terraform Modules & Remote State

**Week 2: Cloud DevOps**  
**Estimated time:** 3–4 hours  
**Focus:** Module design, backends, state locking, workspaces, environments and policy.

## Learning objectives
- Build reusable modules with clear inputs/outputs
- Explain remote state and locking
- Separate dev/stage/prod state
- Prevent accidental production changes

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Create a reusable network module skeleton
2. Create separate environment variable files
3. Document remote backend and locking design
4. Add validation and naming conventions

## Assignment and deliverables
- terraform/modules/network/
- terraform/environments/
- State strategy document

## Checkpoint
Why not share one state file across unrelated environments?
