# Day 08 — Cloud Fundamentals: Azure & AWS

**Week 2: Cloud DevOps**  
**Estimated time:** 3–4 hours  
**Focus:** Cloud shared responsibility, regions, AZs, IAM, compute, storage, networking and cost.

## Learning objectives
- Compare region, availability zone and edge location
- Explain IAM roles/policies and least privilege
- Map common Azure and AWS services
- Identify cost and security guardrails

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Create a cloud service mapping table
2. Draw a simple highly available web app architecture
3. Review IAM/RBAC examples and identify over-permissioning
4. Set a small budget alert if an account is available; otherwise document steps

## Assignment and deliverables
- cloud-service-mapping.md
- Cloud architecture diagram
- IAM least-privilege review

## Checkpoint
Compare Azure VNet and AWS VPC; role vs user.
