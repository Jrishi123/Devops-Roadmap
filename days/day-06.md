# Day 06 — Docker Compose & Container Security

**Week 1: DevOps Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** Multi-container development, health checks, secrets, image hygiene and least privilege.

## Learning objectives
- Define multi-service apps with Compose
- Add health checks and service dependencies
- Reduce image size and attack surface
- Avoid embedding secrets in images

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Create API + PostgreSQL Compose stack
2. Add health checks and persistent DB volume
3. Use environment file locally without committing secrets
4. Scan image with an available scanner and fix obvious issues

## Assignment and deliverables
- compose.yaml
- .env.example (no secrets)
- Container security checklist

## Checkpoint
Why should secrets not be baked into an image?
