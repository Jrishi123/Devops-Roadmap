# Day 03 — Bash Scripting & Python Automation

**Week 1: DevOps Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** Shell scripting, exit codes, arguments, pipes, Python subprocess, files and JSON.

## Learning objectives
- Use variables, conditionals, loops and functions in Bash
- Handle errors and exit codes
- Automate file and command tasks with Python
- Write scripts that are safe to rerun

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Build a log parser that counts INFO/WARN/ERROR lines
2. Write a Python disk-usage reporter
3. Add command-line arguments and input validation
4. Test with normal, empty and missing files

## Assignment and deliverables
- scripts/log_analyzer.py
- scripts/backup_logs.sh
- Sample logs and test output

## Checkpoint
What does set -euo pipefail do? What is an exit code?
