# Day 07 — CI/CD with GitHub Actions

**Week 1: DevOps Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** Workflow triggers, jobs, runners, artifacts, caching, environments and deployment gates.

## Learning objectives
- Explain CI vs continuous delivery vs deployment
- Write workflow YAML
- Run lint/test/build on pull requests
- Use secrets and protected environments safely
