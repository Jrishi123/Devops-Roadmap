# Day 02 — Git, GitHub & Collaboration

**Week 1: DevOps Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** Git internals, commits, branches, remotes, pull requests and conflict resolution.

## Learning objectives
- Configure Git identity and understand working tree/index/repository
- Create meaningful commits and branches
- Push a repository to GitHub
- Resolve a simple merge conflict

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Initialize a repo for the bootcamp labs
2. Create feature/linux-labs branch and commit scripts
3. Push to GitHub and open a pull request
4. Create a deliberate conflict in two branches and resolve it

## Assignment and deliverables
- GitHub repository URL
- At least 5 meaningful commits
- A pull request with summary and test evidence

## Checkpoint
Describe git fetch vs pull; reset vs revert; merge vs rebase.
