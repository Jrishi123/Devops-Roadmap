# Day 12 — Kubernetes Core Concepts

**Week 2: Cloud DevOps**  
**Estimated time:** 3–4 hours  
**Focus:** Control plane, nodes, Pods, Deployments, ReplicaSets, Services, ConfigMaps and Secrets.

## Learning objectives
- Explain Kubernetes architecture
- Deploy and scale a Deployment
- Expose an app with a Service
- Inspect events, logs and resource status

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Use kind or Docker Desktop Kubernetes
2. Deploy Nginx with 2 replicas
3. Expose via ClusterIP and port-forward
4. Inspect describe, logs, events and rollout history

## Assignment and deliverables
- kubernetes/deployment.yaml
- kubernetes/service.yaml
- kubectl command notes

## Checkpoint
Pod vs Deployment; ClusterIP vs NodePort vs LoadBalancer.
