# Day 09 — Cloud Networking & Security

**Week 2: Cloud DevOps**  
**Estimated time:** 3–4 hours  
**Focus:** VNet/VPC, subnets, route tables, NSGs/security groups, NAT, private endpoints and firewalls.

## Learning objectives
- Design public/private subnet segmentation
- Explain ingress/egress and stateful filtering
- Describe private connectivity patterns
- Apply network least privilege

## Suggested schedule
| Activity | Time |

## Practical lab
1. Design hub-and-spoke network with workload spokes
2. Define subnet and route table plan
3. Write sample NSG/security group rules
4. Document private access to a database

## Assignment and deliverables
- architecture/network-design.md
- Firewall and security rules matrix

## Checkpoint
Why keep databases private? NSG vs route table.
