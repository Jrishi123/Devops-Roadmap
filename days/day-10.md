# Day 10 — Terraform Fundamentals

**Week 2: Cloud DevOps**  
**Estimated time:** 3–4 hours  
**Focus:** Providers, resources, variables, outputs, state, plan/apply/destroy and dependency graph.

## Learning objectives
- Understand declarative IaC and Terraform lifecycle
- Write variables, outputs and resources
- Explain state and drift
- Use fmt, validate, plan and apply safely

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Install Terraform
2. Create a local lab using random/local providers or a cloud sandbox
3. Add variables and outputs
4. Run fmt, validate, plan and inspect state
5. Destroy only the lab resources

## Assignment and deliverables
- terraform/main.tf
- variables.tf
- outputs.tf
- terraform lab README

## Checkpoint
What is Terraform state? Why inspect plan before apply?
