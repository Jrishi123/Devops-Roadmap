# Day 28 — Deploy to Kubernetes / AKS

**Week 4: AI + DevOps Integration**  
**Estimated time:** 3–4 hours  
**Focus:** Kubernetes deployment, Helm, ingress, secrets, probes, resources and cloud identity.

## Learning objectives
- Deploy frontend/backend to local Kubernetes or AKS
- Configure Helm values and ingress
- Inject secrets using secure mechanisms
- Validate probes, resources and rollout

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Create Helm chart for capstone services
2. Deploy to kind/minikube; optionally AKS
3. Configure ingress and probes
4. Use Kubernetes Secret only for local lab; document Key Vault CSI/Workload Identity for AKS

## Assignment and deliverables
- helm/capstone/
- Deployment evidence
- Secrets and ingress design notes

## Checkpoint
Explain how production secrets reach pods without hardcoding.
