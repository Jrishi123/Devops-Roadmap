# Day 05 — Docker Fundamentals

**Week 1: DevOps Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** Images, containers, layers, registries, volumes, networks and Dockerfiles.

## Learning objectives
- Explain image vs container and layered builds
- Build and run a container
- Persist data with volumes
- Inspect container logs, networks and resource usage

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Install Docker Desktop for Mac
2. Run Nginx and a small Python/Node app
3. Build a non-root Docker image
4. Use bind mounts and named volumes
5. Inspect logs, exec, inspect and stats

## Assignment and deliverables
- Dockerfile
- compose.yaml
- Container run notes and screenshots

## Checkpoint
Explain CMD vs ENTRYPOINT; bind mount vs volume.
