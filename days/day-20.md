# Day 20 — LLM APIs & Tool Calling

**Week 3: AI Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** API keys, environment variables, retries, rate limits, streaming, tool/function calling and cost control.

## Learning objectives
- Call an LLM API from Python
- Keep API keys out of source control
- Implement timeout/retry and usage logging
- Understand tool calling boundaries

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Build a FastAPI endpoint that sends a prompt to an LLM provider
2. Load keys from environment variables
3. Add request validation, timeout and safe error responses
4. Add mock mode for local testing

## Assignment and deliverables
- ai-service/ FastAPI starter
-  .env.example
- API usage and security notes

## Checkpoint
How do you protect API keys? Why add timeouts and rate limits?
