# Day 19 — Prompt Engineering & Structured Outputs

**Week 3: AI Foundations**  
**Estimated time:** 3–4 hours  
**Focus:** Instruction hierarchy, role/task/context/format, few-shot examples, decomposition and JSON schemas.

## Learning objectives
- Write precise prompts with acceptance criteria
- Use examples to shape output
- Request and validate structured JSON
- Separate trusted instructions from untrusted data

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Create prompts to classify DevOps logs
2. Require JSON output with severity, evidence and next steps
3. Validate output with Pydantic
4. Test malformed and adversarial inputs

## Assignment and deliverables

- schemas/incident.schema.json
- Validation tests
