# Day 13 — Kubernetes Configuration & Storage

**Week 2: Cloud DevOps**  
**Estimated time:** 3–4 hours  
**Focus:** Probes, requests/limits, ConfigMaps, Secrets, volumes, PVCs and StatefulSets.

## Learning objectives
- Configure readiness/liveness/startup probes
- Set CPU/memory requests and limits
- Mount configuration and secrets safely
- Explain PVC and StatefulSet use cases

## Suggested schedule
| Activity | Time |
|---|---:|
| Concepts and notes | 45–60 min |
| Guided lab | 90–120 min |
| Assignment and evidence | 30–45 min |
| Review | 15 min |

## Practical lab
1. Add probes and resources to a sample deployment
2. Mount ConfigMap
3. Create PVC and test persistence
4. Document secret injection options

## Assignment and deliverables
- kubernetes/configmap.yaml
- kubernetes/pvc.yaml
- Updated deployment manifest

## Checkpoint
Readiness vs liveness; PV vs PVC.
