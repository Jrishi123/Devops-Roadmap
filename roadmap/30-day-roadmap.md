# Full 30-Day Roadmap

This is the compact index. Open each linked day for objectives, lab steps, deliverables and checkpoints.

## Week 1 — DevOps Foundations
Build a reliable local engineering workflow: Linux, Git, scripting, networking, containers and CI.

- [Day 01: Linux Fundamentals & Environment Setup](../days/day-01.md) — Linux architecture, filesystem, shell, users, permissions, processes and services.
- [Day 02: Git, GitHub & Collaboration](../days/day-02.md) — Git internals, commits, branches, remotes, pull requests and conflict resolution.
- [Day 03: Bash Scripting & Python Automation](../days/day-03.md) — Shell scripting, exit codes, arguments, pipes, Python subprocess, files and JSON.
- [Day 04: Networking for DevOps](../days/day-04.md) — IP, CIDR, DNS, ports, TCP/UDP, HTTP, TLS, routing and diagnostic tools.
- [Day 05: Docker Fundamentals](../days/day-05.md) — Images, containers, layers, registries, volumes, networks and Dockerfiles.
- [Day 06: Docker Compose & Container Security](../days/day-06.md) — Multi-container development, health checks, secrets, image hygiene and least privilege.
- [Day 07: CI/CD with GitHub Actions](../days/day-07.md) — Workflow triggers, jobs, runners, artifacts, caching, environments and deployment gates.

## Week 2 — Cloud DevOps
Translate foundational skills into cloud infrastructure, Kubernetes delivery, IaC, GitOps and observability.

- [Day 08: Cloud Fundamentals: Azure & AWS](../days/day-08.md) — Cloud shared responsibility, regions, AZs, IAM, compute, storage, networking and cost.
- [Day 09: Cloud Networking & Security](../days/day-09.md) — VNet/VPC, subnets, route tables, NSGs/security groups, NAT, private endpoints and firewalls.
- [Day 10: Terraform Fundamentals](../days/day-10.md) — Providers, resources, variables, outputs, state, plan/apply/destroy and dependency graph.
- [Day 11: Terraform Modules & Remote State](../days/day-11.md) — Module design, backends, state locking, workspaces, environments and policy.
- [Day 12: Kubernetes Core Concepts](../days/day-12.md) — Control plane, nodes, Pods, Deployments, ReplicaSets, Services, ConfigMaps and Secrets.
- [Day 13: Kubernetes Configuration & Storage](../days/day-13.md) — Probes, requests/limits, ConfigMaps, Secrets, volumes, PVCs and StatefulSets.
- [Day 14: Helm, Ingress & GitOps](../days/day-14.md) — Helm charts, values, templates, ingress, release lifecycle, Argo CD/Flux concepts.

## Week 3 — AI Foundations
Learn practical AI/LLM engineering, prompt design, APIs, RAG and evaluation.

- [Day 15: Observability & Incident Response](../days/day-15.md) — Metrics, logs, traces, Prometheus, Grafana, alerts, SLI/SLO, MTTR and runbooks.
- [Day 16: Python for AI Engineering](../days/day-16.md) — Python data structures, functions, typing, virtual environments, packages, APIs and notebooks.
- [Day 17: Machine Learning Concepts](../days/day-17.md) — Features, labels, training/testing, supervised/unsupervised learning, overfitting and evaluation.
- [Day 18: LLMs & Generative AI](../days/day-18.md) — Tokens, context windows, inference, temperature, system/user messages, hallucinations and model limits.
- [Day 19: Prompt Engineering & Structured Outputs](../days/day-19.md) — Instruction hierarchy, role/task/context/format, few-shot examples, decomposition and JSON schemas.
- [Day 20: LLM APIs & Tool Calling](../days/day-20.md) — API keys, environment variables, retries, rate limits, streaming, tool/function calling and cost control.
- [Day 21: Embeddings, Vector Search & RAG](../days/day-21.md) — Embeddings, chunking, vector stores, retrieval, grounding, citations and RAG evaluation.

## Week 4 — AI + DevOps Integration
Build, ship and operate an AI-powered DevOps Assistant as a portfolio project.

- [Day 22: AI Evaluation, Safety & Reliability](../days/day-22.md) — Golden datasets, accuracy, groundedness, latency, cost, prompt injection, privacy and human review.
- [Day 23: Capstone Architecture & API Design](../days/day-23.md) — System boundaries, frontend/backend, ingestion, retrieval, auth, schemas and architecture decisions.
- [Day 24: Build the DevOps Assistant Backend](../days/day-24.md) — FastAPI services, log parsing, RAG pipeline, Pydantic validation, errors and tests.
- [Day 25: Build the Frontend & User Experience](../days/day-25.md) — Next.js UI, API integration, loading/error states, chat history and accessible design.
- [Day 26: Containerize & Test the Capstone](../days/day-26.md) — Multi-stage Docker builds, Compose, health checks, non-root containers and integration tests.
- [Day 27: CI/CD, Quality Gates & Supply Chain](../days/day-27.md) — GitHub Actions, tests, linting, image builds, artifact tagging and deployment approvals.
- [Day 28: Deploy to Kubernetes / AKS](../days/day-28.md) — Kubernetes deployment, Helm, ingress, secrets, probes, resources and cloud identity.
- [Day 29: Monitoring, Runbooks & Reliability](../days/day-29.md) — Service metrics, dashboards, alerts, logs, SLOs, backup/restore and incident playbooks.
- [Day 30: Final Review, Demo & Portfolio Release](../days/day-30.md) — End-to-end validation, documentation, demo, architecture review and portfolio presentation.
