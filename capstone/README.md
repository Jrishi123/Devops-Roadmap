# Capstone — AI-Powered DevOps Assistant

Build a web application that accepts application logs, summarizes likely incidents, and answers operational questions using a curated runbook knowledge base. Every recommendation should show evidence and uncertainty.

MVP: log paste/upload, severity summary, runbook Q&A with citations, FastAPI backend, Next.js frontend, LLM provider abstraction, mock mode, tests, Docker Compose, CI, Kubernetes/Helm deployment, metrics and runbooks.

Non-goals: autonomous production changes; hardcoded credentials; unverified claims of certainty. Require engineer approval for remediation.
